# Main Scraper Options

## Syntax

```
ofscraper [options]
```

### Examples

```
ofscraper
```

or

```
ofscraper --username ALL
```

> ℹ️ **Fork:** a failed run exits with status 1, and bad command-line input prints a short usage message.
