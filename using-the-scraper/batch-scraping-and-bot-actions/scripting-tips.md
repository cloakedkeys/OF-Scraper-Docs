## Windows

### creating shortcut

To pass command-line arguments automatically every time you launch a standalone binary:

1. Create a shortcut (arguments can only be added to shortcuts, not directly to the `.exe` file).
2. Copy the original `.exe`, right-click where you want the shortcut (this can be the same folder), and select **Paste shortcut**:

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

3. Right-click the new shortcut, select **Properties**, and add your arguments to the end of the **Target** field:

<figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>
