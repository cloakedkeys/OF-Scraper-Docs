# Old Menu

Running the prompt menu lets you use OF-Scraper with minimal arguments.

***

## Getting to the main menu

![image](https://user-images.githubusercontent.com/67020411/230734717-e85b02ee-2e66-467a-abe0-2f479c1e6671.png)

The simplest method is to run:

```sh
ofscraper
```

Any command without a scraping option opens this menu.

***

## Edit Profile

![image](https://user-images.githubusercontent.com/67020411/230734759-b16a49da-0b61-44fc-9013-be0b0ac56419.png)

Use this menu to:

* Add profiles
* Change the default profile
* Rename a profile
* Delete a profile

Each profile corresponds to a single account, so multiple accounts require multiple profiles.

***

## Edit config.json

![image](https://user-images.githubusercontent.com/67020411/230734909-5ad9c464-4984-4594-a0de-676344b84697.png)

Use this menu to edit `config.json` directly from inside OF-Scraper without locating the file manually. Your existing settings are pre-filled so you can adjust them easily.

***

## Edit auth.json

> ℹ️ If authentication fails, the authentication menu pops up automatically and prompts you for new settings.

![image](https://user-images.githubusercontent.com/67020411/230735133-9bc6c48f-daed-40be-841c-0d84c3eb2bca.png)

You don't normally need to open this manually, though you can use it to edit `auth.json` directly.
